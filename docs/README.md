# FAK Documentation Pack

This folder separates the Formal Agent Kernel (FAK) idea into three layers:

1. Company/product vision: FAK as a framework-agnostic runtime trust kernel for autonomous AI agents.
2. Commercial wedge: runtime authorization for AI agents before they touch production systems.
3. MSc dissertation scope: structured action validation across SQL and DevOps/shell domains, plus a limited controlled-disclosure demo.
